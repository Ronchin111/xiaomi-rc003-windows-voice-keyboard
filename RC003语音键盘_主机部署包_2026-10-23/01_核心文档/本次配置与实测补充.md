## 2. 「锁定当前按键」实测结论

映射普通按键后，如果物理蓝牙键盘上的 Enter、Space 也失灵，不是两个蓝牙设备冲突。

正确判断：

1. 进入 SayAll 配置页面。
2. 找到「Co 配置」下面的「锁定当前按键」滑动开关。
3. 关闭该滑动开关。
4. 物理键盘和遥控器映射即可同时使用。

该状态不在按键 JSON 里，所以导入 JSON 后必须单独检查。

「锁定当前按键」和「全部按键支持」是两个不同设置。日常都保持关闭；除非明确需要接管返回键、音量键等系统保留键。

## 3. 语音链路

```text
遥控器麦克风
→ Bluetooth LE / ATVV
→ SayAll
→ CABLE Input（播放端）
→ VB-CABLE
→ CABLE Output（录音端）
→ 微信输入法
→ 当前输入框
```

固定配置：

- SayAll 语音设备：`CABLE Input`
- 备选：`CABLE In 16ch`
- 微信输入法麦克风：`CABLE Output`
- 两端热键：`Ctrl + Win`
- 语音触发：按住说话

## 4. 关于“调低输入音量来降噪”

普通系统输入音量本质上是整体增益，不是方向性收音范围。调低后，近处人声和远处噪声会一起降低；微信输入法还可能自动补偿增益。

到了 `CABLE Output` 后，原始遥控器麦克风已经由 SayAll 数字化并写入虚拟线，普通 USB/模拟麦克风的硬件降噪、自动增益和波束成形通常不会继续生效。

VB-CABLE 官方手册说明：Windows 音量控制是否作用于 `CABLE Input`，取决于驱动控制面板中的 Windows Volume Control 选项。若没有启用，普通音量滑块可能无效。

实用优先顺序：

1. 嘴与遥控器保持约 5–10 cm。
2. 避开风扇、空调、键盘敲击方向和强反射面。
3. 在识别稳定的前提下降低入口电平，不要拉到 0。
4. 必要时用 VB-CABLE 控制面板检查实际 Input Level。
5. 不安装 Equalizer APO、ReaGate、VoiceMeeter。
6. 若环境确实嘈杂，改用近嘴耳机麦或领夹麦属于另一条设备方案，不混入本包。

## 6. 排障顺序

### ATVV 状态 1

遥控器休眠。按一下普通键，最多等 60 秒自动重连。不要先重新配对或重启电脑。

### 按键无响应

检查 Windows 是「已连接」还是仅「已配对」；关掉电视/盒子的蓝牙，再唤醒遥控器。

### 物理键盘同名键失灵

关闭「Co 配置 → 锁定当前按键」。

### 完全无声音

检查 SayAll=`CABLE Input`、微信输入法=`CABLE Output`、当前输入法、两边热键、按住说话。
