# 小米蓝牙遥控器 2 Pro（RC003-MS）Windows 语音键盘：主机部署包

- 打包日期：2026-10-23
- 适用目标：Windows 10 / 11 x64 主机
- 目标效果：按住遥控器语音键说话，文字进入当前输入框；普通按键按本包配置执行
- 当前状态：原主机已跑通，新主机尚未验证

## 先做什么

1. 把整个压缩包复制到新主机并解压。
2. 打开解压后的 `Agent部署提示词.md`。
3. 把该文件的全部内容粘贴给新主机上的部署 Agent。
4. 把提示词中的 `<部署包路径>` 换成这台主机上的真实解压路径。

示例：

```text
<部署包路径> = D:\RC003语音键盘_主机部署包_2026-10-23
```

## 包里有什么

- `Agent部署提示词.md`：给另一台主机上 Agent 的完整执行提示词。
- `01_核心文档/`：用户手册、Agent 部署手册、本次实测补充、验收记录模板。
- `02_按键配置/`：SayAll 导出的当前按键配置及逐项说明。
- `03_安装程序/`：SayAll 1.0.0 和 VB-CABLE 2024 驱动包。
- `04_官方资料/`：遥控器官方资料和离线手册副本。
- `05_检查/`：只读健康检查脚本。

## 关键提醒

- 先确认新主机有可用的蓝牙，再开始安装。
- 配置页面的「Co 配置」下，把「锁定当前按键」滑动开关保持关闭。
- 不要开启「全部按键支持」。
- 不要为了这个方案把 Windows 默认播放设备设为 `CABLE Input`。
- 安装 VB-CABLE 后需要重启；必须由用户明确同意，Agent 不得自行重启。
