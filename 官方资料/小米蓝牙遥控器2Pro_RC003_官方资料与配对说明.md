# 小米蓝牙遥控器 2 Pro（RC003-MS）官方资料与配对说明

整理日期：2026-10-23
用途：Windows 下把 RC003-MS 作为蓝牙语音输入遥控器使用，配合无线麦 SayAll。

## 一、先给结论

- 这款是 **Type-C 充电版**，内置 300mAh 电池，**没有电源开关**。
- 机身只有一颗指示灯，**只在充电时亮**：充电中红灯，充满绿灯。**配对时灯不亮**，看不到灯是正常现象。
- 日常使用不需要“开机”。遥控器平时自动休眠，**按任意键就会唤醒**。
- 配对方法：把遥控器靠近目标设备 10–20cm，**同时按住「主页」和「菜单」约 3 秒**，然后在设备端搜索“小米蓝牙语音遥控器”或“MI RC”并连接。

## 四、配对步骤（Windows）

1. 先把电视/盒子断电或关闭蓝牙，避免遥控器优先连回电视。
2. 把遥控器放在电脑旁 10–20cm。
3. 同时按住「主页」和「菜单」约 3 秒。灯不会亮，这是正常的。
4. Windows 打开「设置 → 蓝牙和其他设备 → 添加设备 → 蓝牙」。
5. 在列表中选择「小米蓝牙语音遥控器」或「MI RC」。
6. 配对完成后，设备管理器中应出现 VID_2717 / PID_32B8 的蓝牙 HID 设备。

## 六、与无线麦 SayAll 的关系

- SayAll 只支持 RC001 和 RC003，外观相近的其他遥控器不保证兼容。
- 语音键走 ATVV 私有语音协议，普通按键走标准蓝牙 HID，所以需要 SayAll 这类桥接软件。
- SayAll 报 `发现 ATVV 服务返回状态 1` 时，官方 Issue #112 的解释是：状态 1 = `Unreachable`，代表遥控器还在休眠，属于可自愈状态。按一下普通键唤醒，等它自动重连即可，不需要重新配对。
- 已在本机确认：遥控器在 Windows 中显示为 `MI RC`，VID_2717 / PID_32B8，ATVV 服务 UUID 为 `AB5E0001-5A21-4F05-BC7D-AF01F617B664`。
